# StudyHUB

StudyHUB is a Windows console app for registering students for learning courses and mentoring.

Students can create an account, sign in, choose a school level (SD, SMP, or SMA), and view their selected class schedule. Administrators can view student accounts and registrations.

## Run

Compile `FINALE2_pendaftranPenjadwalan.cpp` with a Windows C++ compiler, then run the program from the same folder. Account and registration data are stored in `users.txt` and `pendaftaran.txt`, created as needed.
